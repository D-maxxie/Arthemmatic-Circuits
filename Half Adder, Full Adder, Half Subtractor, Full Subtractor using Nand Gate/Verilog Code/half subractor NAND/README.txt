# Half Subtractor using NAND Gates (Verilog)

## 📖 Overview

This project implements a **1-bit Half Subtractor** using **only NAND gates** in Verilog HDL. A Half Subtractor subtracts one binary bit (**B**) from another (**A**) and produces two outputs:

- **Difference (Sout)**
- **Borrow (Cout)**

The design demonstrates how subtraction logic can be realized exclusively with **NAND gates**, emphasizing the universality of the NAND gate in digital logic design.

This implementation is intended for educational purposes and provides insight into gate-level arithmetic circuit construction.

## ✨ Features

- 1-bit Half Subtractor

## ⚙️ Functional Description

The Half Subtractor performs the binary subtraction:

```
A − B
```

It generates:

### Difference

```
Difference = A ⊕ B
```

### Borrow

```
Borrow = ¬A · B
```

The XOR and borrow-generation logic are implemented exclusively using interconnected **NAND gates**, eliminating the need for additional logic gates.

---

## 📊 NAND Logic Network

The implementation generates intermediate signals:

```
w0

↓

w1

↓

w2
```

The outputs are obtained as follows:

- **Difference** is produced using a NAND-based XOR network.
- **Borrow** is generated by inverting the appropriate intermediate signal using a NAND gate.
