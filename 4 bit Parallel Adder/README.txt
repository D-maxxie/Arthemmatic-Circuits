# 4-bit Parallel Adder (Ripple Carry Adder) using Verilog

## 📖 Overview

This project implements a **4-bit Parallel Adder**, also known as a **Ripple Carry Adder (RCA)**, using Verilog HDL. The design consists of four **1-bit Full Adders** connected in series to perform the addition of two 4-bit binary numbers along with an optional carry input.

Each Full Adder computes the sum of one bit and propagates its carry to the next stage. The final stage produces the overall carry-out of the addition.

This project demonstrates one of the most fundamental arithmetic circuits used in digital systems and serves as a building block for larger arithmetic units.

## 🏗️ Block Diagram

```
              A[3:0]
                 │
                 │
              B[3:0]
                 │
                 ▼

      +-------------------------+
      |   Parallel Adder (4-bit)|
      |                         |
Cin --> FA0 → FA1 → FA2 → FA3 --> Carry
      |     |     |     |
      ▼     ▼     ▼     ▼
    Sum0  Sum1  Sum2  Sum3
```

Each Full Adder receives:

- One bit from operand **A**
- One bit from operand **B**
- Carry from the previous stage

---

## ⚙️ Functional Description

### Full Adder

Each Full Adder performs:

```
Sum = A ⊕ B ⊕ Cin
```

```
Carry = AB + BCin + ACin
```

---

### Parallel Adder

Four Full Adders are cascaded together.

```
Carry_in

↓

FA0

↓

FA1

↓

FA2

↓

FA3

↓

Carry_out
```

The carry generated by each Full Adder is propagated to the next stage.

## ⏱️ Timing Behavior

- Pure combinational logic
- No clock required
- Carry propagates sequentially through each Full Adder
- Worst-case delay equals the propagation delay of four cascaded Full Adders

## ⚠️ Limitation

Since the carry must ripple through each Full Adder sequentially, the propagation delay increases with operand width. For high-speed arithmetic, architectures such as **Carry Lookahead Adders (CLA)** or **Carry Select Adders (CSA)** are preferred.

## 🔧 Synthesis

- FPGA Compatible ✅
- ASIC Compatible ✅
- Fully Synthesizable RTL ✅
- Pure combinational implementation
- Modular hierarchical design

> **Note:** This implementation uses a **Ripple Carry Adder**, making it compact and easy to understand. However, the carry propagation through each Full Adder increases the critical path delay as the bit width grows. For larger adders requiring higher performance, architectures such as **Carry Lookahead**, **Carry Skip**, or **Carry Select Adders** are more efficient.
