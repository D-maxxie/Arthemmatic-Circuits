# 4-Bit Carry Skip Adder (CSKA) in Verilog

## Overview

This project implements a **4-bit Carry Skip Adder (CSKA)** using Verilog HDL. A Carry Skip Adder is an optimized adder architecture designed to reduce the carry propagation delay found in Ripple Carry Adders. It achieves this by allowing the carry signal to skip an entire block of full adders when all bits in the block satisfy the propagate condition.

The design is built hierarchically using a **1-bit Full Adder**, a **4-bit Parallel Adder**, and the **Carry Skip Adder** module.

## Features

- Implements a 4-bit Carry Skip Adder
- Uses hierarchical module design
- Includes a reusable 1-bit Full Adder
- Employs a 4-bit Ripple Carry Adder as the computation block
- Uses propagate logic to determine whether the carry can skip the block
- Pure combinational logic with no clock dependency
- Fully synthesizable for FPGA and ASIC implementations

## Modules Included

### 1. Full Adder

Performs single-bit binary addition using two input bits and a carry input. It generates the corresponding sum and carry outputs.

### 2. Parallel Adder

Connects four Full Adder modules in series to perform 4-bit binary addition.

### 3. Carry Skip Adder

Uses the output of the Parallel Adder along with propagate logic to determine the final carry output. If all bits propagate the carry, the input carry is passed directly to the output; otherwise, the carry generated by the Parallel Adder is used.

## How It Works

The design first computes the 4-bit sum using a Ripple Carry Adder. At the same time, propagate signals are generated for each bit:

```text
P = A XOR B
```

A single propagate signal (`sel`) is obtained by performing the logical AND of all individual propagate signals.

- If every propagate signal is `1`, the incoming carry is passed directly to the output (`cout = cin`).
- Otherwise, the carry generated by the Ripple Carry Adder is selected.

This carry-skipping mechanism reduces the worst-case carry propagation delay compared to a conventional Ripple Carry Adder.
